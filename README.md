# 排序算法集合

这是一个包含多种常见排序算法的Python实现集合，每种算法都有详细的注释说明其时间复杂度、空间复杂度和稳定性。

## 包含的排序算法

### 1. 冒泡排序 (Bubble Sort)
- **时间复杂度**: O(n²)
- **空间复杂度**: O(1)
- **稳定性**: 稳定
- **特点**: 简单易懂，适合小数据量

### 2. 选择排序 (Selection Sort)
- **时间复杂度**: O(n²)
- **空间复杂度**: O(1)
- **稳定性**: 不稳定
- **特点**: 交换次数少，适合交换成本高的场景

### 3. 插入排序 (Insertion Sort)
- **时间复杂度**: O(n²)
- **空间复杂度**: O(1)
- **稳定性**: 稳定
- **特点**: 对于小数据量或基本有序的数据效率较高

### 4. 快速排序 (Quick Sort)
- **时间复杂度**: 平均O(nlogn)，最坏O(n²)
- **空间复杂度**: O(logn)
- **稳定性**: 不稳定
- **特点**: 实际应用中效率很高，是很多编程语言内置排序的实现

### 5. 归并排序 (Merge Sort)
- **时间复杂度**: O(nlogn)
- **空间复杂度**: O(n)
- **稳定性**: 稳定
- **特点**: 稳定的O(nlogn)算法，适合外部排序

### 6. 堆排序 (Heap Sort)
- **时间复杂度**: O(nlogn)
- **空间复杂度**: O(1)
- **稳定性**: 不稳定
- **特点**: 原地排序，适合内存受限的场景

### 7. 计数排序 (Counting Sort)
- **时间复杂度**: O(n + k)，k为数据范围
- **空间复杂度**: O(k)
- **稳定性**: 稳定
- **特点**: 适用于数据范围不大的整数排序

## 使用方法

### 基本使用

```python
from sorting_algorithms import quick_sort, merge_sort

# 待排序数组
arr = [64, 34, 25, 12, 22, 11, 90]

# 使用快速排序
sorted_arr = quick_sort(arr.copy())
print(sorted_arr)  # [11, 12, 22, 25, 34, 64, 90]

# 使用归并排序
sorted_arr = merge_sort(arr.copy())
print(sorted_arr)  # [11, 12, 22, 25, 34, 64, 90]
```

## 算法选择建议

### 小数据量 (n < 50)
- **插入排序**: 实现简单，对于小数据量效率较高
- **冒泡排序**: 代码简单，适合教学

### 中等数据量 (50 < n < 1000)
- **快速排序**: 平均情况下效率最高
- **归并排序**: 需要稳定排序时使用

### 大数据量 (n > 1000)
- **快速排序**: 首选算法
- **堆排序**: 内存受限时使用
- **归并排序**: 需要稳定排序时使用

### 特殊场景
- **计数排序**: 数据范围不大且为整数时
- **插入排序**: 数据基本有序时

## 注意事项

1. 所有排序函数都会返回排序后的新数组，不会修改原数组
2. 快速排序在最坏情况下时间复杂度为O(n²)，但实际应用中很少遇到
3. 计数排序只适用于整数，且数据范围不能太大
4. 堆排序是原地排序，但会修改原数组
